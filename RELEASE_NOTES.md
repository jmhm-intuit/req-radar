# ReqRadar v1.7.0

## New

- Upload and process multiple PDF or TXT job requisitions in one batch.
- Compact ranking table designed for 30+ requisitions, with pagination and sticky headers.
- Show/hide each status from the overview, including Not pursuing.
- Upload a resume and maintain a confirmed skills profile.
- Skills Fit with green matched, amber partial, red missing, and critical-gap classifications.
- Interest Fit based on personal interests and lower-interest work, with manual overrides.
- Automatic Do not pursue recommendation for jobs posted more than 90 days ago, with an exception toggle.
- Networking stages, contact, and notes for each requisition.
- Transparent recommendation score and suggested next action.
- Manual rank adjustment, priority, pinning, skill overrides, and recommendation overrides.
- Backup schema v3 includes profile, rankings, networking, links, settings, and filters.

## Compatibility

- Imports legacy ReqRadar v1.5 and v1.6 backups.
- Static browser-only app for GitHub Pages. Data remains in localStorage unless exported.
