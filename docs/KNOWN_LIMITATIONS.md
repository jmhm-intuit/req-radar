# Questline 4.2 Known Limitations

- Personal records remain local to each browser profile; synchronization is manual through Excel or JSON.
- Google and Outlook calendar snapshots are imported read-only. Hiding an event affects only Questline.
- Actual elapsed time is not tracked. Review uses Attention Footprint and optional estimates.
- Task destination movement preserves lineage but does not merge two Tasks.
- A Task has one active Project or Exploration parent at a time.
- Projects and Explorations support one-level workstreams and investigation threads; nested Projects are not included.
- Automatic Review History summarizes source data; optional narrative reflection is still entered separately.
- Global search remains available but was not expanded in this release.
