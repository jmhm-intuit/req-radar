# Questline 4.2 Mobile Usage

## Review open Tasks

Open Tasks. Choose a destination tab—Resolve, Project, Exploration, Renew/Fun, or All—then optionally filter by Scheduled, Unscheduled, or Overdue.

## Change what a Task belongs to

Open the Task's three-dot menu and select **Change destination**. Choose Resolve, Project, Exploration, or Renew/Fun. When choosing a Project or Exploration, select its workstream or investigation thread. All Task progress and history are preserved.

## Change only the date

Use Date or Replan from the Task row. This changes scheduling only and does not change the Task's destination.

## Review progress

Review opens on Areas. Progress shows the canonical weekly trend. History contains automatic summaries for completed weeks and months with Activity history.

## Inspect a life area

Open an area card to view its Tasks. Needs Focus cards explain the active important records that are not moving.
