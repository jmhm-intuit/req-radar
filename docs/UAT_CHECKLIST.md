# Questline 4.2 User-Acceptance Checklist

## Task mobility

- [ ] Resolve, Project, Exploration, and Renew/Fun appear as category tabs.
- [ ] All, Scheduled, Unscheduled, and Overdue work as separate filters.
- [ ] A Resolve Task can move into a Project and workstream.
- [ ] A Resolve Task can move into an Exploration and investigation thread.
- [ ] A Project or Exploration Task can detach into Resolve or Renew/Fun.
- [ ] A Task can move to another Project or Exploration.
- [ ] Dates, checklist, progress, stars, rank inputs, areas, and notes survive movement.
- [ ] Date/Replan changes only the date.

## Task presentation

- [ ] Rank and Star stay in fixed positions with wrapped titles.
- [ ] Rank ordering is descending within each Task group.
- [ ] Overdue treatment is visually distinct from Rank.
- [ ] At least four compact Task cards fit in a normal mobile viewport when metadata is short.

## Review integrity

- [ ] Review opens on Areas.
- [ ] Hero completed count matches the current Weekly Trend total.
- [ ] Pace comparison uses the same current and previous period totals.
- [ ] Rolling average label reflects the number of periods actually available.
- [ ] Shared life areas do not increase the global completed total.
- [ ] Area cards display one non-duplicated set of values.
- [ ] Recovery images load without placeholders.
- [ ] Recovery View All opens the complete list.

## Review history

- [ ] Prior completed weeks appear automatically in History.
- [ ] Prior completed months appear automatically in History.
- [ ] Weeks and Months filters work.
- [ ] Existing manual reviews remain available.

## Mobile and PWA

- [ ] No horizontal page overflow at 320, 360, 390, or 430 pixels.
- [ ] Bottom navigation does not cover Review controls or the final card.
- [ ] Offline relaunch works after first load.
- [ ] Installed PWA updates to Version 4.2.0.

## Data

- [ ] JSON export/import round trip works.
- [ ] Excel export/import round trip works.
- [ ] Migration from Version 4.1 preserves personal records.
